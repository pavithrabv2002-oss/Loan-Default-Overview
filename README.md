## Loan Default Overview — Power BI

### Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)

### Project Overview
An interactive Power BI dashboard designed to analyse loan applications and provide insights into borrower profiles and loan default patterns.

### Key Features
- KPI cards to summarise loan data
- Visual analysis of loan applications and default status
- Borrower and loan characteristic comparisons
- Interactive filtering and dashboard exploration

### Key Learnings
-Building an interactive Power BI dashboard
-Presenting data through visualisations and KPI cards
-Using data analysis to support business understanding
